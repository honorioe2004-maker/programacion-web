Portafolio de Proyectos Académicos y Técnicos

A continuación se detallan algunos de los proyectos más significativos que he desarrollado durante mi formación en ingeniería de software, reflejando tanto la aplicación de bases de datos relacionales como el diseño de arquitecturas lógicas de control.

Proyecto 1: Sistema de Modelado de Base de Datos Relacional (Atraco Cibernético)

Descripción General: Diseño completo y arquitectura de un esquema relacional complejo desarrollado íntegramente en MySQL Workbench. Este proyecto consistió en la creación de múltiples tablas interconectadas mediante estrictas restricciones de claves primarias y foráneas, asegurando la consistencia transaccional y la integridad referencial de los registros.

Componentes Técnicos: Creación de sentencias DDL y DML avanzadas, normalización de tablas hasta la tercera forma normal (3FN), y redacción de scripts de inserción de datos masivos para pruebas de rendimiento.

Tecnologías Empleadas: SQL, MySQL Workbench, Modelado Entidad-Relación (ER).

Proyecto 2: Plataforma de Registro de Métricas y Control Cuantitativo

Descripción General: Creación de un marco lógico automatizado y hojas de cálculo avanzadas orientadas al registro sistemático de parámetros operativos, evaluación de riesgos matemáticos y control de resultados en entornos de simulación algorítmica.

Componentes Técnicos: Implementación de fórmulas complejas de procesamiento estadístico, validaciones estrictas de reglas de cumplimiento y diseño visual estructurado para la toma de decisiones basada en datos empíricos.

Tecnologías Empleadas: Lógica computacional aplicada, herramientas de análisis cuantitativo y estructuración de datos tabulares.
